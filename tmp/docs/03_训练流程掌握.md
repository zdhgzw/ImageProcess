## 二、train.py核心参数配置

### 2.1 基础配置参数

**编辑 `train.py` 文件**（第40-112行）：

```python
if __name__ == "__main__":
    #---------------------------------#
    #   Cuda配置
    #---------------------------------#
    Cuda = True  # GPU训练设为True，CPU设为False

    #---------------------------------#
    #   随机种子（可复现实验）
    #---------------------------------#
    seed = 11  # 固定随机种子，每次训练结果一致

    #---------------------------------#
    #   分布式训练配置（多GPU）
    #---------------------------------#
    distributed = False  # 单卡训练设为False
    sync_bn = False      # 仅DDP模式下启用
    fp16 = False         # 混合精度训练（显存不足时启用）

    #---------------------------------#
    #   数据集配置（重要！）
    #---------------------------------#
    num_classes = 21     # 类别数+1（VOC为21，自定义数据集需修改）
    backbone = "vgg"     # 主干网络：vgg 或 resnet50

    #---------------------------------#
    #   预训练权重配置
    #---------------------------------#
    pretrained = False   # 是否加载主干预训练权重
    model_path = "model_data/unet_vgg_voc.pth"  # 完整模型路径
    # model_path = ""    # 从0开始训练（不推荐）

    #---------------------------------#
    #   输入尺寸（必须是32的倍数）
    #---------------------------------#
    input_shape = [512, 512]  # 常用: [256,256], [416,416], [512,512]
```

**关键参数说明**：

| 参数 | 说明 | 取值建议 |
|-----|------|---------|
| `Cuda` | 是否使用GPU | GPU可用时设为`True` |
| `num_classes` | 类别数+1 | VOC=21, 二分类=3, 自定义按实际+1 |
| `backbone` | 主干网络 | `vgg`速度快，`resnet50`精度高 |
| `model_path` | 预训练模型路径 | 有模型就填路径，无则留空`""` |
| `input_shape` | 输入尺寸 | 必须是32的倍数，推荐512 |

### 2.2 训练策略配置（两阶段训练）

**冻结训练 + 解冻训练**（第156-172行）：

```python
#------------------------------------------------------------------#
#   冻结阶段：冻结主干网络，仅训练解码器部分
#   优点：显存占用小，训练稳定
#------------------------------------------------------------------#
Init_Epoch = 0           # 起始epoch（断点续训时修改）
Freeze_Epoch = 50        # 冻结训练的epoch数
Freeze_batch_size = 2    # 冻结阶段的batch size

#------------------------------------------------------------------#
#   解冻阶段：解冻所有网络，完整训练
#   优点：模型性能更好
#------------------------------------------------------------------#
UnFreeze_Epoch = 100     # 总共训练的epoch数
Unfreeze_batch_size = 2  # 解冻阶段的batch size

#------------------------------------------------------------------#
#   是否进行冻结训练
#------------------------------------------------------------------#
Freeze_Train = True      # True=两阶段训练，False=直接解冻训练
```

**训练策略建议**：

| 场景 | Freeze_Epoch | UnFreeze_Epoch | Freeze_Train |
|------|--------------|----------------|--------------|
| 小数据集(<500) | 50 | 100-150 | True |
| 中等数据集(500-2000) | 30 | 80-120 | True |
| 大数据集(>2000) | 0 | 100-200 | False |
| 显存不足 | 80 | 100 | True |

### 2.3 优化器与学习率配置

```python
#------------------------------------------------------------------#
#   学习率配置
#------------------------------------------------------------------#
Init_lr = 1e-4           # 初始学习率（Adam推荐1e-4, SGD推荐1e-2）
Min_lr = Init_lr * 0.01  # 最小学习率（通常为Init_lr的1%）

#------------------------------------------------------------------#
#   优化器选择
#------------------------------------------------------------------#
optimizer_type = "adam"  # 可选：adam, sgd
momentum = 0.9           # SGD动量参数
weight_decay = 0         # 权重衰减（Adam时设为0，SGD时设为1e-4）

#------------------------------------------------------------------#
#   学习率衰减策略
#------------------------------------------------------------------#
lr_decay_type = 'cos'    # 可选：cos(余弦退火), step(阶梯下降)
```

**优化器选择建议**：

| 优化器 | Init_lr | weight_decay | 特点 |
|-------|---------|--------------|------|
| Adam | 1e-4 | 0 | 收敛快，适合快速实验 |
| SGD | 1e-2 | 1e-4 | 最终精度高，需要更多epoch |

**学习率衰减对比**：

```python
# cos（余弦退火）：学习率平滑下降
# 适用场景：大多数情况，训练稳定

# step（阶梯下降）：每隔一定epoch突然下降
# 适用场景：需要在特定阶段快速收敛
```

### 2.4 损失函数配置

```python
#------------------------------------------------------------------#
#   损失函数权重
#------------------------------------------------------------------#
cls_weights = np.ones([num_classes], np.float32)  # 每个类别的权重
dice_loss = False  # 是否使用Dice Loss
focal_loss = False # 是否使用Focal Loss
```

**损失函数组合策略**：

| 场景 | dice_loss | focal_loss | 说明 |
|------|-----------|-----------|------|
| 类别平衡 | False | False | 仅CE Loss |
| 类别不平衡 | False | True | Focal Loss处理不平衡 |
| 小目标分割 | True | False | Dice Loss关注重叠度 |
| 极度不平衡 | True | True | 组合使用 |

### 3.2 batch_size设置指南

**根据GPU显存**：

| GPU显存 | input_shape | backbone | Freeze_batch | Unfreeze_batch |
|---------|-------------|----------|--------------|----------------|
| 2GB | [256,256] | vgg | 2 | 1 |
| 4GB | [512,512] | vgg | 4 | 2 |
| 6GB | [512,512] | vgg | 8 | 4 |
| 8GB+ | [512,512] | resnet50 | 16 | 8 |
| 12GB+ | [512,512] | resnet50 | 32 | 16 |

**关键规则**：
- ✅ `Freeze_batch_size ≈ 1-2 × Unfreeze_batch_size`
- ✅ ResNet50时batch_size不能为1（有BatchNorm层）
- ✅ 显存不足时先减小batch_size，再减小input_shape

**正常训练**：
```
Epoch 10 - train_loss: 0.523 || val_loss: 0.467
Epoch 20 - train_loss: 0.432 || val_loss: 0.389
Epoch 30 - train_loss: 0.321 || val_loss: 0.298
```
✅ 训练损失和验证损失都在下降

**过拟合**：
```
Epoch 10 - train_loss: 0.523 || val_loss: 0.467
Epoch 20 - train_loss: 0.232 || val_loss: 0.512  ← 验证损失上升
Epoch 30 - train_loss: 0.121 || val_loss: 0.687
```
❌ 训练损失下降，验证损失上升或不变

**解决方法**：
1. 增加数据增强强度
2. 减小模型复杂度
3. 提前停止训练
4. 增加训练数据

**欠拟合**：
```
Epoch 80 - train_loss: 0.723 || val_loss: 0.756
Epoch 90 - train_loss: 0.718 || val_loss: 0.751
Epoch 100 - train_loss: 0.715 || val_loss: 0.749
```
❌ 损失值较高且不再下降

**解决方法**：
1. 增加训练epoch
2. 提高学习率
3. 使用更复杂的模型（如ResNet50）
4. 检查数据标签质量

## 七、训练技巧与调优

### 7.1 学习率调优技巧

**学习率过大**：
```
Epoch 5 - train_loss: 1.234
Epoch 10 - train_loss: nan  ← 损失变成nan
```
解决：减小`Init_lr`为原来的0.1-0.5倍

**学习率过小**：
```
Epoch 50 - train_loss: 0.956
Epoch 60 - train_loss: 0.954  ← 几乎不下降
Epoch 70 - train_loss: 0.952
```
解决：增大`Init_lr`为原来的2-5倍

### 7.2 数据增强调整

**编辑 `utils/dataloader.py`** 中的增强参数（第100+行）：

```python
# 在get_random_data函数中
```

## 十、常见训练问题排查

### 问题1：CUDA out of memory

```
RuntimeError: CUDA out of memory. Tried to allocate XX MiB
```

**解决方案（按顺序尝试）**：
1. 减小batch_size（`Freeze_batch_size = 1`）
2. 启用混合精度（`fp16 = True`）
3. 减小输入尺寸（`input_shape = [256, 256]`）
4. 使用CPU训练（`Cuda = False`）

### 问题2：损失变成nan

```
Epoch 10 - train_loss: nan || val_loss: nan
```

**原因与解决**：
- 学习率过大 → 减小`Init_lr`为0.1倍
- 数据标签错误 → 检查标签像素值范围
- 梯度爆炸 → 启用梯度裁剪（需修改代码）

### 问题3：维度不匹配

```
RuntimeError: size mismatch, m1: [x x], m2: [y y]
```

**原因**：`num_classes` 与模型不匹配

**解决**：
```python
# 情况1：从预训练模型训练，类别数不同
model_path = "model_data/unet_vgg_voc.pth"  # VOC模型，21类
num_classes = 3  # 你的数据集3类

# 解决：从0开始训练或仅加载主干
model_path = ""
pretrained = True

# 情况2：断点续训时num_classes改变了
# 解决：确保num_classes与之前训练一致
```

### 问题4：训练速度极慢

```
100%|████| 250/250 [45:00<00:00, 10.8s/it]  ← 每个epoch 45分钟
```

**优化方法**：
1. 检查是否使用GPU（`Cuda = True`）
2. 减小输入尺寸（`input_shape = [256, 256]`）
3. 减少数据增强计算（修改dataloader）
4. 使用更快的主干网络（vgg比resnet50快）

### 问题5：验证损失不下降

```
Epoch 50 - train_loss: 0.123 || val_loss: 0.456  ← val_loss卡住
Epoch 60 - train_loss: 0.089 || val_loss: 0.455
Epoch 70 - train_loss: 0.067 || val_loss: 0.454
```

**可能原因**：
- 验证集与训练集分布不同
- 学习率过小，陷入局部最优
- 数据增强过强，验证集无法泛化

**解决**：
1. 检查数据集划分是否合理
2. 适当提高学习率
3. 减弱数据增强强度
4. 延长训练epoch
