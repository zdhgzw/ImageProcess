### 3.2 配置推理参数

**编辑 `unet.py` 文件**，找到 `_defaults` 配置（约第26行）：

```python
_defaults = {
    #-------------------------------------------------------------------#
    #   model_path指向logs文件夹下的权值文件
    #   训练好后logs文件夹下存在多个权值文件，选择验证集损失较低的即可
    #   验证集损失较低不代表miou较高，仅代表该权值在验证集上泛化性能较好
    #   如果出现shape不匹配，一定要注意训练时的num_classes、
    #   model_path和num_classes的修改
    #-------------------------------------------------------------------#
    "model_path"        : 'model_data/unet_vgg_medical.pth',
    #--------------------------------#
    #   所需要区分的类的个数+1
    #--------------------------------#
    "num_classes"       : 2,
    #--------------------------------#
    #   所使用的的主干网络：vgg、resnet50
    #--------------------------------#
    "backbone"          : "vgg",
    #--------------------------------#
    #   输入图片的大小
    #--------------------------------#
    "input_shape"       : [512, 512],
    #-------------------------------------------------#
    #   mix_type参数用于控制检测结果的可视化方式
    #
    #   mix_type = 0的时候代表原图与生成的图进行混合
    #   mix_type = 1的时候代表仅保留生成的图
    #   mix_type = 2的时候代表仅扣去背景，仅保留原图中的目标
    #-------------------------------------------------#
    "mix_type"          : 0,
    #--------------------------------#
    #   是否使用Cuda
    #   没有GPU可以设置成False
    #--------------------------------#
    "cuda"              : False,
}
```

**关键参数说明**：
- `model_path`: 模型权重文件路径
- `num_classes`: **医学数据集为2**（1类目标+背景）
- `backbone`: 主干网络，默认`vgg`
- `input_shape`: 输入尺寸，医学图像为512×512
- `cuda`: CPU推理设为`False`，GPU设为`True`

## 六、理解项目核心流程（必读）

### 6.1 推理流程图

```
用户图片
   ↓
预处理（resize、归一化）
   ↓
UNet模型推理
   ↓
后处理（argmax、上色）
   ↓
可视化输出
```

### 6.2 关键文件说明

| 文件 | 作用 | 何时修改 |
|-----|------|---------|
| `unet.py` | 推理封装类 | 切换模型、调整参数时 |
| `predict.py` | 预测脚本 | 切换预测模式时 |
| `nets/unet.py` | 网络结构 | 一般不修改 |
| `model_data/*.pth` | 预训练权重 | 训练完成后替换 |

### 6.3 核心概念

**num_classes**（重要！）
- VOC数据集：21（20类物体+背景）
- 医学数据集：2（1类目标+背景）
- **公式**：`num_classes = 实际类别数 + 1`

**backbone主干网络**
- `vgg`：速度快，精度中等，推荐入门
- `resnet50`：精度高，速度稍慢

**input_shape输入尺寸**
- 必须是32的倍数（UNet架构要求）
- 常用尺寸：[256,256]、[512,512]、[416,416]
- 越大精度越高，速度越慢

## 九、故障排除

### 问题1：模型加载失败
```bash
# 检查模型文件是否存在
ls -lh model_data/unet_vgg_medical.pth

# 检查配置是否匹配
```

### 问题2：推理结果全黑
**原因**：num_classes配置错误

**解决**：
```python
# 医学数据集模型
num_classes = 2

# VOC数据集模型
num_classes = 21
```

### 问题3：显存不足（GPU）
```python
# 方法1：减小输入尺寸
input_shape = [256, 256]

# 方法2：使用CPU推理
cuda = False
```

### 问题4：Mac M1/M2芯片问题
```bash
# 使用MPS加速（PyTorch 1.12+）
```
