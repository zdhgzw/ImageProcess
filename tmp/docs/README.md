**版本**: v1.0

## 📚 学习路线概览

本学习路线采用**实战导向**的方式，在12天内掌握从数据准备到模型部署的完整流程。

### 学习目标

- ✅ **快速上手**：1小时内跑通完整推理流程
- ✅ **核心技能**：掌握数据准备、训练调优、模型评估
- ✅ **项目实战**：独立完成一个完整的分割项目
- ❌ **跳过内容**：理论推导、非VOC数据集、医学图像相关

### 学习阶段

```
阶段一：快速启动（第1天）
    → 跑通完整流程，建立全局认知

阶段二：核心模块深入（第2-5天）
    → 掌握工程必需的核心模块

阶段三：生产实战（第6-12天）
    → 自定义数据集完整项目
```

## 🚀 开始学习

### 第一步：环境准备

```bash
# 1. 克隆项目（如果需要）
git clone https://github.com/bubbliiiing/unet-pytorch.git
cd unet-pytorch

# 2. 创建虚拟环境
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# 或 .venv\Scripts\activate  # Windows

# 3. 安装依赖
pip install -r requirements.txt

# 4. 验证安装
python -c "import torch; print(torch.__version__)"
```

### 第二步：开始学习

```bash
# 打开第一天的学习文档
# 推荐使用Markdown阅读器或GitHub网页版

python predict.py  # 单图预测模式
```
