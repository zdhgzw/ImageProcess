## 一、数据集格式要求（必读）

### 1.1 VOC标准格式结构

```
VOCdevkit/
└── VOC2007/
    ├── JPEGImages/              # 原始RGB图像（.jpg格式）
    │   ├── 0001.jpg
    │   ├── 0002.jpg
    │   └── ...
    ├── SegmentationClass/       # 像素级标签（.png格式）
    │   ├── 0001.png
    │   ├── 0002.png
    │   └── ...
    └── ImageSets/
        └── Segmentation/
            ├── train.txt        # 训练集列表（无扩展名）
            ├── val.txt          # 验证集列表
            ├── trainval.txt     # 训练+验证集
            └── test.txt         # 测试集列表
```

### 1.2 关键格式要求（重要！）

**原始图片（JPEGImages/）**：
- ✅ 必须是 `.jpg` 格式
- ✅ 尺寸可以不固定（训练时自动resize）
- ✅ 灰度图会自动转为RGB
- ❌ 其他格式（png、bmp等）需要批量转换

**标签图片（SegmentationClass/）**：
- ✅ 必须是 `.png` 格式（8位灰度图或8位彩图）
- ✅ **每个像素点的值 = 该像素所属的类别ID**
- ✅ 背景像素值为 `0`
- ✅ 第1类目标像素值为 `1`
- ✅ 第2类目标像素值为 `2`
- ❌ **常见错误**：目标像素值为255（必须改为1）

**文件名对应关系**：
```
JPEGImages/0001.jpg  ←→  SegmentationClass/0001.png
```
文件名必须完全一致（不含扩展名）。

### 2.3 标注操作步骤

**步骤1：打开图片**
- File → Open → 选择图片

**步骤2：创建多边形标注**

**步骤3：设置类别标签**
- 弹出对话框输入类别名称（如 `cat`、`dog`）
- 确保类别名称与后续配置一致

**步骤4：保存标注**
- File → Save
- 自动生成同名 `.json` 文件

## 五、数据加载器原理（源码解读）

### 5.1 数据加载流程

**文件路径**：`utils/dataloader.py`

```python
# 核心类：UnetDataset
class UnetDataset(Dataset):
    def __init__(self, annotation_lines, input_shape, num_classes, ...):
        # annotation_lines: 图片ID列表
        # input_shape: 输入尺寸 [512, 512]
        # num_classes: 类别数+1

    def __getitem__(self, index):
        # 1. 读取图片和标签
        jpg = Image.open(jpg_path)
        png = Image.open(png_path)

        # 2. 数据增强
        jpg, png = self.get_random_data(jpg, png, ...)

        # 3. 预处理
        jpg = preprocess_input(jpg)  # 归一化
        png = np.array(png)          # 转为numpy

        # 4. 转换为one-hot编码
        seg_labels = np.eye(num_classes)[png]

        return jpg, png, seg_labels
```

### 5.2 数据增强策略

**在 `dataloader.py` 中的 `get_random_data` 函数**：

```python
def get_random_data(self, image, label, input_shape, jitter=.3, hue=.1, sat=0.7, val=0.3, random=True):
    """
    数据增强包括：
    1. 随机缩放（jitter控制）
    2. 随机翻转（左右翻转）
    3. HSV色彩抖动（hue/sat/val控制）
    4. resize到固定尺寸
    """
```

**增强参数含义**：
- `jitter=0.3`: 随机缩放范围为[0.7, 1.3]
- `hue=0.1`: 色调随机偏移±10%
- `sat=0.7`: 饱和度随机缩放0.3-1.7倍
- `val=0.3`: 亮度随机缩放0.3-1.7倍

## 八、常见错误与解决方案

### 错误1：标签像素值为0和255
```
打印像素点的值与数量。
|   0  | 1234567 |
| 255  |  567890 |

检测到标签中像素点的值仅包含0与255，数据格式有误。
二分类问题需要将标签修改为背景的像素点值为0，目标的像素点值为1。
```

**原因**：
- Labelme默认生成二值化标签（0/255）
- `json_to_dataset.py` 中classes配置错误

**解决**：
```python
# 确保classes列表包含所有标注的类别
classes = ["_background_", "cat", "dog"]  # 必须与Labelme标注一致
```

### 错误2：标签是RGB三通道图
```
标签图片img001.png的shape为(512, 512, 3)，不属于灰度图
```

**原因**：labelme版本不兼容

**解决**：
```bash
pip uninstall labelme
pip install labelme==3.16.7
# 重新运行 json_to_dataset.py
```

### 错误3：文件名不匹配
```
FileNotFoundError: VOCdevkit/VOC2007/JPEGImages/img001.jpg
```

**原因**：JPEGImages和SegmentationClass中文件名不一致

**解决**：
```bash
# 检查文件名
ls VOCdevkit/VOC2007/JPEGImages/ | head
ls VOCdevkit/VOC2007/SegmentationClass/ | head

# 确保文件名完全对应（除扩展名）
```

### 错误4：类别数量不匹配
```
训练时报错：IndexError: index out of range
```

**原因**：标签中的像素值超出了num_classes范围

**解决**：
```python
# 检查标签像素值
import numpy as np
from PIL import Image

png = Image.open('VOCdevkit/VOC2007/SegmentationClass/img001.png')
print("像素值范围:", np.unique(np.array(png)))

# 如果有类别3，但num_classes=3，则会出错
# 应该设置 num_classes = 4（3类+背景）
```

## 九、批量数据处理工具脚本

### 9.1 批量转换图片格式

```python
# convert_to_jpg.py - 批量转换为JPG格式
import os
from PIL import Image
from tqdm import tqdm

input_dir = "raw_images/"
output_dir = "jpg_images/"
os.makedirs(output_dir, exist_ok=True)

for filename in tqdm(os.listdir(input_dir)):
    if filename.lower().endswith(('.png', '.bmp', '.jpeg')):
        img_path = os.path.join(input_dir, filename)
        img = Image.open(img_path).convert('RGB')

        # 保存为JPG
        new_name = os.path.splitext(filename)[0] + '.jpg'
        img.save(os.path.join(output_dir, new_name), 'JPEG', quality=95)
        print(f"Converted: {filename} -> {new_name}")
```

### 9.2 数据集统计脚本

```python
# dataset_stats.py - 统计数据集信息
import os
import numpy as np
from PIL import Image
from collections import Counter

VOC_path = "VOCdevkit/VOC2007"
seg_dir = os.path.join(VOC_path, "SegmentationClass")

# 统计所有标签的像素值分布
all_pixels = []
for png_file in os.listdir(seg_dir):
    if png_file.endswith('.png'):
        png_path = os.path.join(seg_dir, png_file)
        png = np.array(Image.open(png_path))
        all_pixels.extend(png.flatten())

# 统计
counter = Counter(all_pixels)
print("=" * 50)
print("数据集像素值统计")
print("=" * 50)
for pixel_value, count in sorted(counter.items()):
    percentage = count / len(all_pixels) * 100
    print(f"类别 {pixel_value}: {count:>10} 像素 ({percentage:.2f}%)")
print("=" * 50)
```
