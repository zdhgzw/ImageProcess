## 数据准备问题

### Q4: 标签像素值为0和255

**问题**：
```
检测到标签中像素点的值仅包含0与255，数据格式有误。
二分类问题需要将标签修改为背景的像素点值为0，目标的像素点值为1。
```

**原因**：Labelme默认生成二值化标签

**解决方案**：

方法1：修改 `json_to_dataset.py` 中的classes配置
```python
# 确保classes列表包含所有标注的类别
classes = ["_background_", "cat", "dog"]  # 必须与Labelme标注的名称一致
```

方法2：使用格式修复工具
```bash
# 下载官方格式修复工具
git clone https://github.com/bubbliiiing/segmentation-format-fix.git

# 运行修复
python segmentation-format-fix/fix_labels.py
```

方法3：手动修复脚本
```python
import os
import numpy as np
from PIL import Image
from tqdm import tqdm

label_dir = "VOCdevkit/VOC2007/SegmentationClass"

for filename in tqdm(os.listdir(label_dir)):
    if not filename.endswith('.png'):
        continue

    filepath = os.path.join(label_dir, filename)
    label = np.array(Image.open(filepath))

    # 将255改为1
    label[label == 255] = 1

    # 保存
    Image.fromarray(label.astype(np.uint8)).save(filepath)

print("修复完成")
```

### Q5: 标签是RGB三通道图

**问题**：
```
标签图片xxx.png的shape为(512, 512, 3)，不属于灰度图
```

**原因**：labelme版本不兼容或保存格式错误

**解决方案**：

方法1：重装labelme 3.16.7
```bash
pip uninstall labelme
pip install labelme==3.16.7

# 重新运行json_to_dataset.py
python json_to_dataset.py
```

方法2：批量转换为灰度图
```python
import os
import numpy as np
from PIL import Image

label_dir = "VOCdevkit/VOC2007/SegmentationClass"

for filename in os.listdir(label_dir):
    if not filename.endswith('.png'):
        continue

    filepath = os.path.join(label_dir, filename)
    img = Image.open(filepath)

    # 如果是RGB，转为灰度
    if len(np.array(img).shape) == 3:
        # 取第一个通道
        gray = np.array(img)[:, :, 0]
        Image.fromarray(gray).save(filepath)
        print(f"转换: {filename}")
```

```bash
missing_labels = jpg_files - png_files
```

### Q8: 损失变成nan

**问题**：

**可能原因与解决方案**：

原因1：学习率过大
```python

```

原因2：梯度爆炸
```python

```

原因3：数据标签错误
```python
# 检查标签像素值范围
import numpy as np
from PIL import Image

label = np.array(Image.open("VOCdevkit/VOC2007/SegmentationClass/0001.png"))

print(f"唯一值: {np.unique(label)}")

# 应该在 [0, num_classes-1] 范围内
```

原因4：输入数据异常
```python
# 检查是否有NaN值
def check_data(dataloader):
    for imgs, labels in dataloader:
        if torch.isnan(imgs).any():

            print("发现NaN标签！")
            break
```

## 最佳实践总结

### 数据准备最佳实践

#### 1. 数据标注规范

```
✅ DO:
- 类别名称统一（建议使用小写英文）
- 边界尽量精确
- 小目标也要标注
- 遮挡目标根据可见部分标注

❌ DON'T:
- 类别名称不一致（如"Cat"和"cat"）
- 标注边界过于粗糙
- 漏标小目标
- 随意猜测遮挡部分
```

#### 2. 数据集划分策略

```python
# 小数据集（<500张）
train : val = 80% : 20%

# 中等数据集（500-2000张）
train : val : test = 70% : 20% : 10%

# 大数据集（>2000张）
train : val : test = 80% : 10% : 10%
```

#### 3. 数据增强策略

```python
# 数据充足时（>1000张）
jitter = 0.3   # 中等强度
hue, sat, val = 0.1, 0.7, 0.3

# 数据不足时（<500张）
jitter = 0.5   # 强增强
hue, sat, val = 0.2, 1.0, 0.5

# 医学影像（不宜过强）
jitter = 0.1   # 弱增强
hue, sat, val = 0.05, 0.3, 0.1
```

### 训练配置最佳实践

#### 1. 优化器选择

```python
# 快速实验、小数据集

Init_lr = 1e-4
weight_decay = 0

# 最终训练、大数据集
```

#### 2. 学习率设置

```python
Init_lr = 1e-4 (Adam) 或 1e-2 (SGD)

# ResNet50主干
backbone = "resnet50"
Init_lr = 1e-4 (Adam) 或 7e-3 (SGD)
```

#### 3. Batch size推荐

